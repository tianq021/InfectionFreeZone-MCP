# 地图分块读取方案（2026-11-10）

## 一、方案核心思想

**把 6,749 栋建筑按地理位置切成网格块，客户端只读需要的块。**

### 1.1 地图尺寸估算

根据 `WorldData.cs:113-120`，地图有 `Map.Bound`（平面边界）和 `Map.RawBound`（原始边界）。

假设地图尺寸（典型城市地图）：
- `Map.Bound`：约 2000 × 2000 世界单位
- 切成 **10 × 10 网格** → 每块 200 × 200 单位
- 每块约 **67 栋建筑**（6749 / 100）

### 1.2 读取策略

| 场景 | 当前 | 分块后 |
|------|------|--------|
| 搜刮附近建筑（500m 半径） | 68 页 / 1.58 MB | **1-3 块 / 70-200 KB** |
| 全图扫描 | 68 页 / 1.58 MB | 按需读 **10-20 块 / 700 KB-1.4 MB** |
| 无行动 | 每 15 秒全扫 | **0 块 / 0 KB** |

## 二、实现方案

### 方案 A：客户端过滤（零改动插件，立即生效）

**原理**：插件返回全量数据，但客户端只解析需要的部分。

**优点**：零改动 | **缺点**：带宽没节省（仍传输全量）

```javascript
// server.mjs 新增：客户端过滤
async function getWorldDataFiltered(category, filters) {
  if (category === 'buildings') {
    // 一次性读取全量（68 页）
    const allBuildings = await readAllPages('buildings');

    // 客户端过滤
    let result = allBuildings;

    if (filters.can_scavenge !== undefined) {
      result = result.filter(b => b.can_scavenge === filters.can_scavenge);
    }
    if (filters.scavenged !== undefined) {
      result = result.filter(b => b.scavenged === filters.scavenged);
    }
    if (filters.near_x !== undefined && filters.near_z !== undefined) {
      const radius = filters.near_radius || 500;
      result = result.filter(b => {
        const dx = b.position.x - filters.near_x;
        const dz = b.position.z - filters.near_z;
        return Math.sqrt(dx*dx + dz*dz) <= radius;
      });
    }

    return { items: result, filtered: true, total: allBuildings.length };
  }

  return getWorldData(category, { offset: 0, limit: 100 });
}
```

**收益**：AI 只看到过滤后的数据 | **但带宽仍浪费**

### 方案 B：插件端分块读取（推荐，改动小收益大）

**原理**：插件新增 `buildings_chunk` 类目，按网格返回建筑。

#### B.1 网格划分逻辑

```csharp
// 新增：在 WorldData.cs 中
private static readonly int ChunkSize = 200; // 每块 200 × 200 世界单位

private object ReadBuildingChunk(JObject args)
{
    RequireSession(args);

    // 解析参数
    var centerX = (double?)args["center_x"] ?? 0;
    var centerZ = (double?)args["center_z"] ?? 0;
    var radius = (double?)args["radius"] ?? 200;
    var canScavenge = (bool?)args["can_scavenge"];
    var scavenged = (bool?)args["scavenged"];

    // 计算边界
    var minX = centerX - radius;
    var maxX = centerX + radius;
    var minZ = centerZ - radius;
    var maxZ = centerZ + radius;

    // 查询范围内的建筑
    var buildings = container.Resolve<BuildingsController>().Buildings
        .Where(building => building != null)
        .Where(b =>
            b.CenterPosition.x >= minX && b.CenterPosition.x <= maxX &&
            b.CenterPosition.z >= minZ && b.CenterPosition.z <= maxZ
        )
        .Where(b => canScavenge == null || b.CanScavenge() == canScavenge)
        .Where(b => scavenged == null || b.IsScavenged() == scavenged)
        .Select(building => new
        {
            id = building.Id,
            position = Position(building.CenterPosition),
            can_scavenge = building.CanScavenge(),
            scavenged = building.IsScavenged(),
            stockroom = building.IsStockroom()
            // 去掉 osm_id 和 bounds（节省 40% 体积）
        })
        .ToArray();

    return new
    {
        session_id = sessionId,
        center_x = centerX,
        center_z = centerZ,
        radius = radius,
        chunk_count = buildings.Length,
        items = buildings
    };
}
```

### 方案 C：预计算网格索引（最优，但改动稍大）

**原理**：游戏启动时预计算建筑网格索引，读取时 O(1) 定位。

#### C.1 启动时构建索引

```csharp
// Plugin.cs 中 OnWorldInitialized 后
private static Dictionary<string, List<Building>> buildingGrid = new();

private static void BuildBuildingGrid()
{
    buildingGrid.Clear();
    var buildings = worldContainer.Resolve<BuildingsController>().Buildings;

    foreach (var building in buildings)
    {
        if (building == null) continue;

        // 计算建筑所属网格键
        var gridX = (int)Math.Floor(building.CenterPosition.x / ChunkSize);
        var gridZ = (int)Math.Floor(building.CenterPosition.z / ChunkSize);
        var key = $"{gridX},{gridZ}";

        if (!buildingGrid.ContainsKey(key))
            buildingGrid[key] = new List<Building>();

        buildingGrid[key].Add(building);
    }

    Logger.LogInfo($"Building grid: {buildingGrid.Count} chunks, {buildings.Count()} total buildings");
}
```

#### C.2 读取时直接定位网格

```csharp
private object ReadBuildingChunkOptimized(JObject args)
{
    RequireSession();

    var centerX = (double?)args["center_x"] ?? 0;
    var centerZ = (double?)args["center_z"] ?? 0;
    var radius = (double?)args["radius"] ?? 200;

    // 计算需要读取的网格范围
    var minGridX = (int)Math.Floor((centerX - radius) / ChunkSize);
    var maxGridX = (int)Math.Floor((centerX + radius) / ChunkSize);
    var minGridZ = (int)Math.Floor((centerZ - radius) / ChunkSize);
    var maxGridZ = (int)Math.Floor((centerZ + radius) / ChunkSize);

    var result = new List<object>();

    // 只读取涉及的网格
    for (var gx = minGridX; gx <= maxGridX; gx++)
    {
        for (var gz = minGridZ; gz <= maxGridZ; gz++)
        {
            var key = $"{gx},{gz}";
            if (!buildingGrid.TryGetValue(key, out var buildings)) continue;

            foreach (var building in buildings)
            {
                // 圆形过滤（网格是方形，需要二次过滤）
                var dx = building.CenterPosition.x - centerX;
                var dz = building.CenterPosition.z - centerZ;
                if (dx*dx + dz*dz > radius*radius) continue;

                result.Add(new
                {
                    id = building.Id,
                    position = Position(building.CenterPosition),
                    can_scavenge = building.CanScavenge(),
                    scavenged = building.IsScavenged(),
                    stockroom = building.IsStockroom()
                });
            }
        }
    }

    return new
    {
        session_id = sessionId,
        center_x = centerX,
        center_z = centerZ,
        radius = radius,
        chunk_count = result.Count,
        items = result.ToArray()
    };
}
```

**性能对比**：

| 方案 | 查询方式 | 建筑数 | 耗时 |
|------|----------|--------|------|
| **当前（全量分页）** | LINQ Where+Select | 6,749 | 1.34-1.83 s |
| **方案 B（边界过滤）** | LINQ Where（带坐标） | ~200-500 | ~50-100 ms |
| **方案 C（网格索引）** | 字典 O(1) + 少量 LINQ | ~67 | **~5-10 ms** |
