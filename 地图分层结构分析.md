# 地图分层结构分析（2026-11-10）

## 一、地图层级结构

根据用户反馈和游戏代码，地图有**多层嵌套结构**：

```
地图总览
├── 聚落区域（ Settlement ）
│   ├── 总部（HQ）所在的核心区域
│   └── 建筑密集区（居民区、工业区）
├── 3×3 网格（中尺度）
│   └── 每个格子 ~600-1000 世界单位
├── 5×5 网格（大尺度）
│   └── 每个格子 ~1500-2500 世界单位
└── 远征地域（Expedition Map）
    └── 独立的大方块区域，与聚落地图分离
```

### 1.1 代码证据

**聚落地图**：
- `Map.Bound` — 聚落平面边界
- `Map.RawBound` — 原始边界（含高程）
- `worldMap.TileSize` — 瓦片尺寸
- `worldMap.CityName` — 城市名称

**远征地图**：
- `worldMap.BoundExtend` — 远征地图边界（`UnitControl.cs:166`）
- `squad.IsOnExpedition()` — 判断小队是否在远征（多处使用）

```csharp
// UnitControl.cs:166 - 远征地图边界检查
if (!worldMap.BoundExtend.Contains(new Vector2(x, z)))
    throw new BridgeException("target_out_of_range", "Choose a point within the expedition map.");
```

**关键区别**：
- **聚落地图**：建筑密集，6,749 栋建筑
- **远征地图**：独立方块，虚拟群组（virtual_groups）活动区域

## 二、地图数据结构分析

### 2.1 聚落地图（Settlement Map）

**数据源**：`BuildingsController.Buildings`

```csharp

    .Where(building => building != null)
    .Select(building => new {
        id = building.Id,
        osm_id = building.OsmId.ToString(),
        position = Position(building.CenterPosition),
        bounds = Bounds(building.AABB),
        completed = building.IsCompleted,
        can_scavenge = building.CanScavenge(),
        scavenged = building.IsScavenged(),
        stockroom = building.IsStockroom()
    })
```

**特征**：
- 6,749 栋建筑（实测）
- 按 `Map.Bound` 分布（平面矩形）
- 建筑类型：住宅、商业、工业、仓库等

### 2.2 远征地图（Expedition Map）

**数据源**：`VirtualGroupsController.Groups`

```csharp
// WorldData.cs:69-81
"virtual_groups" => container.Resolve<VirtualGroupsController>().Groups
    .Where(group => group != null)
    .Select(group => new {
        id = group.ID,
        type = group.Type,
        faction = group.Fraction.ToString(),
        position = Position(group.Position),
        destination = Position(group.Movement.Target),
        visible = group.IsVisible(),
        hostile_to_player = group.IsVisible() && squads.Squads.Any(...),
        member_count = group.ICharacters.Count
    })
```

**特征**：
- 虚拟群组（远征中的小队、敌对远征队）
- 按 `worldMap.BoundExtend` 分布（独立方块）
- 建筑少（或无），主要是群组活动

### 2.3 实体群组（Groups）

**数据源**：`GroupsController.Groups`

```csharp
// WorldData.cs:65-68
"groups" => container.Resolve<GroupsController>().Groups
    .Where(group => group != null && !group.IsDestroying)
    .Select(group => ReadGroup(group, hostile: true))
```

**特征**：
- 感染者、土匪、幸存者等
- 可在聚落地图和远征地图活动
- 最多 32 名成员/组（含明细）

### 4.1 聚落地图：200×200 网格

**适用**：建筑、小队、群组

```csharp
    var radius = (double?)args["radius"] ?? 200;

    // 检查是否在聚落地图边界内

        throw new BridgeException("out_of_bounds", "Point is outside the settlement map.");

    // 读取 200×200 网格
    var result = ReadBuildingsInChunk(centerX, centerZ, radius);

    return new { map_type = "settlement", ... };
}
```

### 4.2 远征地图：独立分块

**适用**：虚拟群组、远征小队

```csharp
// 远征地图分块
case "expedition_chunk":
{
    var centerX = (double?)args["center_x"] ?? 0;
    var centerZ = (double?)args["center_z"] ?? 0;
    var radius = (double?)args["radius"] ?? 500;

    // 检查是否在远征地图边界内
    if (!worldMap.BoundExtend.Contains(new Vector2(centerX, centerZ)))
        throw new BridgeException("out_of_expedition", "Point is outside the expedition map.");

    // 读取远征区域内的虚拟群组
    var virtualGroups = container.Resolve<VirtualGroupsController>().Groups
        .Where(group => group != null)
        .Where(g => {
            var dx = g.Position.x - centerX;
            var dz = g.Position.z - centerZ;
            return dx*dx + dz*dz <= radius*radius;
        })
        .Select(g => new {
            id = g.ID,
            type = g.Type,
            faction = g.Fraction.ToString(),
            position = Position(g.Position),
            member_count = g.ICharacters.Count,
            visible = g.IsVisible()
        })
        .ToArray();

    return new {
        map_type = "expedition",
        center_x = centerX,
        center_z = centerZ,
        radius = radius,
        group_count = virtualGroups.Length,
        items = virtualGroups
    };
}
```

### 4.3 智能地图类型检测

```csharp
// 自动检测坐标属于哪个地图
private static string DetectMapType(double x, double z)
{
    if (Map.Bound.Contains(new Vector2(x, z)))
        return "settlement";

    if (worldMap.BoundExtend.Contains(new Vector2(x, z)))
        return "expedition";

    throw new BridgeException("out_of_bounds", "Point is not on any valid map.");
}

// 统一入口
case "map_chunk":
{
    var centerX = (double?)args["center_x"] ?? 0;
    var centerZ = (double?)args["center_z"] ?? 0;
    var radius = (double?)args["radius"] ?? 200;

    var mapType = DetectMapType(centerX, centerZ);

    if (mapType == "settlement")
        return ReadBuildingsInChunk(centerX, centerZ, radius);
    else
        return ReadExpeditionInChunk(centerX, centerZ, radius);
}
```

## 七、完整实现代码

### 7.1 C# 插件端

```csharp
// ===== WorldData.cs 新增 =====

private static readonly int ChunkSize = 200;
private static Dictionary<string, List<Building>> buildingGrid = null;
private static bool gridBuilt = false;

// 构建聚落地图网格
private static void BuildSettlementGrid()
{
    if (gridBuilt) return;

    buildingGrid = new Dictionary<string, List<Building>>();
    var buildings = worldContainer.Resolve<BuildingsController>().Buildings;

    foreach (var building in buildings)
    {
        if (building == null) continue;

        var gridX = (int)Math.Floor((building.CenterPosition.x - Map.Bound.xMin) / ChunkSize);
        var gridZ = (int)Math.Floor((building.CenterPosition.z - Map.Bound.yMin) / ChunkSize);
        var key = $"{gridX},{gridZ}";

        if (!buildingGrid.ContainsKey(key))
            buildingGrid[key] = new List<Building>();

        buildingGrid[key].Add(building);
    }

    gridBuilt = true;
    Logger.LogInfo($"Settlement grid built: {buildingGrid.Count} chunks");
}

// 读取聚落地图指定区域
private static object ReadSettlementChunk(JObject args)
{
    RequireSession();
    if (!gridBuilt) BuildSettlementGrid();

    var centerX = (double?)args["center_x"] ?? 0;
    var centerZ = (double?)args["center_z"] ?? 0;
    var radius = (double?)args["radius"] ?? 200;
    var canScavenge = (bool?)args["can_scavenge"];
    var scavenged = (bool?)args["scavenged"];

    // 边界检查
    if (!Map.Bound.Contains(new Vector2(centerX, centerZ)))
        throw new BridgeException("out_of_bounds", "Point is outside the settlement map.");

    // 计算网格范围
    var minGridX = (int)Math.Floor((centerX - radius - Map.Bound.xMin) / ChunkSize);
    var maxGridX = (int)Math.Floor((centerX + radius - Map.Bound.xMin) / ChunkSize);
    var minGridZ = (int)Math.Floor((centerZ - radius - Map.Bound.yMin) / ChunkSize);
    var maxGridZ = (int)Math.Floor((centerZ + radius - Map.Bound.yMin) / ChunkSize);

    var cols = (int)Math.Ceiling((Map.Bound.xMax - Map.Bound.xMin) / ChunkSize);
    var rows = (int)Math.Ceiling((Map.Bound.yMax - Map.Bound.yMin) / ChunkSize);
    minGridX = Math.Max(0, minGridX);
    maxGridX = Math.Min(cols - 1, maxGridX);
    minGridZ = Math.Max(0, minGridZ);
    maxGridZ = Math.Min(rows - 1, maxGridZ);

    // 读取网格
    var result = new List<object>();

    for (var gx = minGridX; gx <= maxGridX; gx++)
    {
        for (var gz = minGridZ; gz <= maxGridZ; gz++)
        {
            var key = $"{gx},{gz}";
            if (!buildingGrid.TryGetValue(key, out var buildings)) continue;

            foreach (var building in buildings)
            {
                var dx = building.CenterPosition.x - centerX;
                var dz = building.CenterPosition.z - centerZ;
                if (dx * dx + dz * dz > radius * radius) continue;

                if (canScavenge.HasValue && building.CanScavenge() != canScavenge.Value) continue;
                if (scavenged.HasValue && building.IsScavenged() != scavenged.Value) continue;

                result.Add(new {
                    id = building.Id,
                    position = Position(building.CenterPosition),
                    can_scavenge = building.CanScavenge(),
                    scavenged = building.IsScavenged(),
                    stockroom = building.IsStockroom()
                });
            }
        }
    }

    return new {
        map_type = "settlement",
        center_x = centerX,
        center_z = centerZ,
        radius = radius,
        chunks_read = (maxGridX - minGridX + 1) * (maxGridZ - minGridZ + 1),
        building_count = result.Count,
        items = result.ToArray()
    };
}

// 读取远征地图指定区域
private static object ReadExpeditionChunk(JObject args)
{
    RequireSession();

    var centerX = (double?)args["center_x"] ?? 0;
    var centerZ = (double?)args["center_z"] ?? 0;
    var radius = (double?)args["radius"] ?? 500;

    // 边界检查
    if (!worldMap.BoundExtend.Contains(new Vector2(centerX, centerZ)))
        throw new BridgeException("out_of_expedition", "Point is outside the expedition map.");

    // 读取虚拟群组
    var virtualGroups = container.Resolve<VirtualGroupsController>().Groups
        .Where(group => group != null)
        .Where(g => {
            var dx = g.Position.x - centerX;
            var dz = g.Position.z - centerZ;
            return dx * dx + dz * dz <= radius * radius;
        })
        .Select(g => new {
            id = g.ID,
            type = g.Type,
            faction = g.Fraction.ToString(),
            position = Position(g.Position),
            member_count = g.ICharacters.Count,
            visible = g.IsVisible()
        })
        .ToArray();

    return new {
        map_type = "expedition",
        center_x = centerX,
        center_z = centerZ,
        radius = radius,
        group_count = virtualGroups.Length,
        items = virtualGroups
    };
}
```

## 八、总结

### 地图结构总结

| 地图类型 | 边界属性 | 主要数据 | 分块策略 | 网格尺寸 |
|----------|----------|----------|----------|----------|
| **聚落地图** | `Map.Bound` | 建筑 6,749 + 群组 15 | 200×200 网格 | 100 块 |
| **远征地图** | `BoundExtend` | 虚拟群组 5-20 | 独立大方块 | 按需划分 |

### 关键区别

| 特性 | 聚落地图 | 远征地图 |
|------|----------|----------|
| 建筑数 | 6,749 | 0-10 |
| 群组数 | 15（实体） | 5-20（虚拟） |
| 小队类型 | 玩家小队 | 远征小队 |
| 边界检查 | `Map.Bound` | `BoundExtend` |
| 数据量 | 1.58 MB | ~10-50 KB |
| 分块后（500m） | ~65 KB | ~5-20 KB |
