================================================================
一、项目介绍
================================================================

本项目把《无感染区 / Infection Free Zone》游戏本体接成一个本地 MCP 服务，让 AI
（Codex / DSH 等客户端）在同一局游戏里与玩家 1 倍速同步协作。

架构：
  游戏进程（Unity + BepInEx 插件）
    └─ 命名管道（请求/响应，帧式 JSON）
  Node.js 服务 server.mjs（标准 MCP stdio，20 个工具）
    ├─ client.mjs       命令行客户端 / coop、captain 工作流入口
    ├─ coop.mjs         1 倍速协作：预告 → 短暂停 → 下单 → 恢复 1 倍速 → 回读
    ├─ captain.mjs      本地模型队长：读局势 → 选动作 → 发原生订单
    └─ captain-model.mjs 本地 Ollama 模型适配（默认 qwen3:1.7b）

适用：本机 Steam build 26104777、Windows x64、Unity Mono。
测试副本：.local/game（通过 scripts/Start-TestGame.ps1 启动）。

- 协作层：coop（brief / check / scavenge / return，含分段计时）、captain（本地模型队长，

3.4 关键结论（影响后续实现）
- 游戏返回数据量排名：buildings（约 1.58 MB/68 页）>> groups（每群最多 32 人明细，
  约几十 KB）> squads（约 6.8 KB）> events（约 4 KB）> vehicles（约 2.6 KB）。
- “只查变化”分两层：AI 侧可由 runtime 缓存 + 差分 + 事件实现（P0 即可）；
  桥接侧当前无版本号/脏标记/推送，要源头只查变化需插件增强（world_probe /
  world_snapshot / buildings 过滤）。
- 中断与消息不丢失：DSH 的 session/cancel 使用 keepInbox=true，保留排队与引导消息；
  已派发工具调用的结果会提交、未派发工具调用落 abort 错误结果，历史保持合法；
  但 cancel 后不会自动继续队列，调度器必须“cancel → prompt”成对唤醒。
- 大脑选型：不用本地小模型兜底，只用 DSH 会话（DeepSeek），即时性靠事件与异步执行器。
- 地图分块方案：10×10 网格（200×200 单位/块），共 100 块；聚落地图与远征地图分层；
  障碍物由 A* 寻路系统内置（node.Walkable），无需额外标记；
  客户端按需读取区域数据，预计减少 95-99% 带宽。
